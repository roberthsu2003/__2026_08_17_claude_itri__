## prompt1
```
請使用 Playwright 開啟 momo 購物網（https://www.momoshop.com.tw）：

1. 在搜尋框中輸入『毛寶 小蘇打洗碗精 無香精』並進行搜尋，先幫我記錄我方產品的促銷價格與規格。
2. 接著，重新搜尋『小蘇打洗碗精』，尋找其他競爭品牌（例如橘子工坊、茶籽堂、淨毒五郎等）的類似產品。
3. 幫我收集前 5 筆競品商品的『品牌名稱』、『商品名稱』、『容量』與『促銷價格』。
4. 將我方產品與這 5 筆競品進行交叉對比，整理成一個 Markdown 比較表格，並針對我們產品的價格競爭力提供簡單的對比建議。

5. 接著把上述結果存成 Excel 檔（.xlsx），規格如下：
   - 檔名：momo小蘇打洗碗精競品分析_YYYYMMDD.xlsx（日期用今天）
   - 工作表 1「競品比較」：欄位依序為 品牌名稱、商品名稱、容量(ml)、促銷價格(元)、每 100ml 單價(元)、是否為我方產品。
     我方產品放第一列，其餘 5 筆競品接在後面。
   - 「每 100ml 單價」請用公式計算，並依此欄由低到高排序（我方產品那列請用底色標示，方便一眼看出位置）。
   - 工作表 2「分析建議」：放第 4 點的價格競爭力分析文字。
   - 標題列請加粗、凍結首列、欄寬自動調整。

6. 最後，將這個 Excel 檔上傳到我的 Google Drive「上課用」資料夾中。
   請先搜尋確認「上課用」資料夾存在並取得其 ID，再把檔案上傳進去；
   上傳完成後回報檔案連結，若找不到該資料夾就先問我，不要自行建立新資料夾。
```
